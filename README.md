# FOOTBALL CAREER: DYNASTY

Mobile-first 2D football management game made with Godot 4.4.1.

## Playable systems in this first build
- Club creation with country and division selection (Italy, England, Spain, France, Germany).
- Procedurally generated 22-player squad with age, rating, potential, morale, fitness, injuries, contracts and statistics.
- 16-team, 30-matchday league season with standings.
- Matchday simulation, player condition and morale updates, match income and wages.
- Transfer market with transfer fee, weekly wage, contract length and promised squad role.
- Player sales, club finances, national cup knockout rounds and a basic European qualification flag.
- Tactical choices and local save/load.

All player names and clubs in the generated database are fictional placeholders. Real-world player and club data, logos and images are not included.

## Run
Open this folder in Godot 4.4.1 and press Play.

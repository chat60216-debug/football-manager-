# Real football roster data

The game can import real club squads from the OpenFootballBase data release.

- Source project: https://github.com/florentfougeres/OpenFootballBase-Data
- Season imported: 2026/27
- Supported covered competitions: ENG-PL, ENG-CH, ESP-LL, ESP-SD, ITA-SA, ITA-SB, DEU-BL, DEU-B2, FRA-L1, FRA-L2.
- Data is built from Wikipedia (CC BY-SA 4.0) and Wikidata (CC0). The source page/revision metadata remains in the upstream release.
- The imported roster file is generated by `scripts/import_openfootballbase.py` and refreshed weekly by GitHub Actions.

Important: the upstream project does not provide complete squads for every third-tier division selectable in this game. Those divisions continue using generated player squads until an appropriately licensed, verifiable dataset is available. Do not describe generated players as real footballers.

## Third-tier club-name references

Third-tier club lists are kept separate from the imported player-roster file because the upstream release does not publish complete squads for these competitions.

- Italy, Serie C 2026/27: official Lega Pro communication 30/L (three groups of 20): https://www.seriec.com/storage/app/media/comunicati/2026-2027/Lega/2627-30L.pdf
- England, League One and League Two 2026/27: current 24-club lists: https://footbeen.com/blog/92-club-guide-visit-every-english-football-league-ground
- France, Ligue 3 2026/27: current 18-club list: https://championnat.net/saison/2026-27/

Names and league membership are factual reference data; player squads for these divisions remain generated in-game and are labelled as such.
